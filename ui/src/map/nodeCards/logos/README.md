# Technology logos

React, Vue, Angular, Rust, Redis and PostgreSQL SVGs from Devicon v2.17.0 (MIT).
Source: https://github.com/devicons/devicon/tree/v2.17.0/icons
Full license: `LICENSE-devicon.txt`. Rust uses a light fill for the dark map surface.
Logos identify the technologies; their names and marks belong to their respective owners.

TaskHub adds Chrome, Envoy, Next.js, NestJS, FastAPI, Go, Python, Node.js, RabbitMQ and Kubernetes from Devicon
commit `4fbcc685c9a85434bc01b1c236c9076f54806236` (MIT, same `LICENSE-devicon.txt`). Each is the
`icons/<name>/<name>-original.svg` file, unchanged.

- Keycloak: https://github.com/keycloak/keycloak-web/blob/main/resources/images/icon.svg
  (source blob `44798d21c8b9bba777d6daefea655d5447bc0f5f`, Apache-2.0; `keycloak/LICENSE.txt`).
- OpenSearch: https://github.com/opensearch-project/project-website/blob/main/assets/brand/SVG/Mark/opensearch_mark_darkmode.svg
  (source blob `dbf66a04b4d92d13c36e0d1bb57b60775dd2042e`, BSD-3-Clause; `opensearch/LICENSE.txt`).
- `network`, `loadBalancer` and `s3`: original neutral interface symbols, under this project's MIT OR Apache-2.0
  license. They identify generic infrastructure or the S3 interface without assuming a cloud vendor.

All logos are local SVG assets with no scripts or remote references. No icon package or external runtime request
is required. Technology labels in the TaskHub simulator describe its reference architecture, not installed services.
